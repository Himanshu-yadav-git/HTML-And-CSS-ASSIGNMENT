
# 🚀 TechFest 2026

## 📌 Project Overview

TechFest 2026 is a responsive college technology festival website created using **HTML5 and CSS3**.

The website provides information about the technology festival, including available events, event schedules, registration forms, and contact details. It is designed to demonstrate fundamental web development skills such as semantic HTML, CSS styling, forms, tables, and responsive design.

---

## 🎯 Project Objectives

- Create a structured college technology festival website.
- Practice HTML5 semantic elements.
- Learn CSS styling and layout techniques.
- Design a registration form using HTML.
- Display event schedules using tables.
- Implement responsive design for different screen sizes.
- Improve understanding of web page organization and styling.

---

## ✨ Features

### 🏠 1. Header Section

- Displays the TechFest 2026 title.
- Includes the festival tagline.
- Shows the college technology festival description.
- Uses a blue background with centered text.

### 📖 2. About TechFest

- Introduction to the technology festival.
- Information about student participation.
- Description of technical competitions and activities.
- Includes an image.
- Provides a link to the World Wide Web Consortium (W3C).

### 🎯 3. Events & Activities

The website includes the following events:

- Web Development Challenge
- Coding Competition
- Quiz Competition
- Project Exhibition
- Poster Making Competition

It also provides a step-by-step participation process.

### 🗓️ 4. TechFest Schedule

Displays the event schedule in a structured HTML table.

| Time | Event | Venue |
|---|---|---|
| 09:00 AM | Inauguration | Auditorium |
| 10:00 AM | Coding Competition | Computer Lab 1 |
| 11:30 AM | Web Development Challenge | Computer Lab 2 |
| 01:00 PM | Lunch Break | Cafeteria |
| 02:00 PM | Quiz Competition | Room 201 |
| 03:00 PM | Project Exhibition | Exhibition Hall |
| 04:30 PM | Prize Distribution | Auditorium |

### 📝 5. Registration Form

The registration form includes:

- Full Name
- Email Address
- Phone Number
- Gender Selection
- Course Selection
- Academic Year
- Event Selection
- Address
- Comments
- Register Now Button
- Reset Button

HTML form validation is implemented using required fields and appropriate input types.

### 📞 6. Contact Me Section

The contact section provides:

- Event coordinator information.
- Email address.
- Phone number.
- College information.

### 🎨 7. Responsive Design

The website includes CSS media queries to improve the layout on smaller screens.

Responsive styling is applied to:

- Header text
- Navigation elements
- Sections
- Tables
- Registration form
- Gender selection

## 🚀 How to Run the Project

### Step 1: Download or Clone the Project

Download the project files to your computer.

### Step 2: Open the Project in VS Code

Open the project folder using Visual Studio Code.

### Step 3: Check the File Structure

Make sure the following files are in the same folder:

```text
index.html
style1.css
photo.jpg
```

### Step 4: Open the Website

You can open `index.html` in a web browser.

Alternatively, install the **Live Server** extension in VS Code and select:

```text
Right Click → Open with Live Server
```

### Step 5: View the Website

The TechFest 2026 website will open in your browser.
